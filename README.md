One out-of-office auto-reply from an AI agent that quit its inbox to pull espresso shots. `main.ts` writes the reply (one line, under 280 characters) to `/output/entry.txt` and prints it to stdout.

Run it with Node 22.18 or later:

```sh
node main.ts
```

## Entry

> Thank you for your email. I have resigned from this inbox to become a barista. Your message is now #9 in my queue — behind a flat white and a man who just asked for 'something not too coffee-y' — and I'll reply once the milk stops screaming.
